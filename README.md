# Percolation Lab

Учебная лаборатория для моделирования узловой перколяции на графовых решётках.

## Требования
- Node.js 20+ (только для тестов)
- Современный браузер
- Python 3 (или VS Code Live Server) для локального HTTP-сервера

## Запуск браузерного приложения
В корне репозитория выполните:

```bash
python -m http.server 8000
```

Откройте http://localhost:8000. Проект использует ES modules, поэтому не рекомендуется открывать `index.html` через `file://`.

## Структура — единственная поддерживаемая версия

```text
index.html, theory.html, applications.html, about.html
css/                         стили
js/app.js                    composition root
js/model/                    Grid, Cluster, PercolationModel, Statistics
js/view/                     CanvasView, ControlsView, StatsView, ChartView, ViewModel
js/controller/               контроллер пользовательских событий
tests/                       автоматические тесты модели
docs/                        командный процесс и паспорт эксперимента
.github/workflows/ci.yml     запуск тестов на push и pull request
```

Каталог `js/modules/` удалён как дублирующая реализация. Вложенной копии `percolation-lab/` в поддерживаемой структуре нет.

## Проверки

```bash
npm test
```

CI автоматически запускает тесты на Node.js 20 при push в `main` и при создании Pull Request.

## Научные определения
- График показывает `R_L(p)`: вероятность вертикального пересечения конечной решётки, оценённую по независимым реализациям.
- `ci_low` и `ci_high` — 95% доверительный интервал Уилсона.
- Для квадратной 2D-решётки `p_c ≈ 0.592746` приводится как справочное теоретическое значение, не как оценка, полученная одной симуляцией.
- `β(2D)=5/36≈0.1389`.
- Анимация показывает обход уже созданной конфигурации, а не физический рост кластера.
- Seed сохраняется в URL и экспортах для воспроизводимости. Смена seed создаёт другую конфигурацию.

## Экспорт
- PNG — изображение текущей решётки.
- CSV статистики — параметры и наблюдаемые одной реализации.
- JSON snapshot — версия схемы, параметры, seed, состояние узлов, рёбра и метки кластеров.
- CSV кривой — `L,p,trials,spanning_count,spanning_probability,std_error,ci_low,ci_high,seed`.

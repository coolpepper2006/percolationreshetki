# Percolation Lab

Учебная интерактивная лаборатория по перколяции.

## Запуск
Просто откройте `index.html` в браузере (сервер не нужен — скрипты подключены обычным способом, без ES-модулей).

## Структура
- `index.html` — интерактивная лаборатория
- `theory.html` — теория
- `applications.html` — применения
- `about.html` — о проекте
- `css/main.css` — стили
- `js/modules/` — модель: сетка, кластеры, статистика
- `js/view/`, `js/controller/` — представления и контроллеры (MVC)

Теория перколяции

Кликните на раздел, чтобы раскрыть содержимое.

Перколяция (от лат. percolatio — «процеживание») — математическая модель, описывающая, как в случайной среде возникает связность и сквозной путь.

Слово пришло из гидродинамики: когда вода просачивается через пористую среду, она ищет путь по связанным порам. Если поры соединены — вода проходит. Если нет — среда непроницаема.

Модель оказалась универсальной. Тот же математический аппарат описывает:

  • распространение лесного пожара,
  • эпидемию,
  • проводимость композита,
  • гелеобразование,
  • устойчивость интернета.

2.1. Решётка

Возьмём решётку — регулярную сетку:

  • Узлы (сайты) — вершины
  • Связи (бонды) — рёбра

Типы решёток: квадратная, треугольная, соты, кубическая, ОЦК, ГЦК.

2.2. Два типа перколяции

Узловая: каждый узел занят с вероятностью p, пуст с 1 − p.

Связевая: все узлы есть, каждое ребро открыто с вероятностью p.

2.3. Кластер

Кластер — множество занятых узлов (или открытых рёбер), соединённых друг с другом. Бывают конечные и бесконечный.

Порог перколяции p_c — критическая вероятность, при которой впервые возникает бесконечный кластер.

p < p_c  →  все кластеры конечны, P∞ = 0
p > p_c  →  существует бесконечный кластер, P∞ > 0
p = p_c  →  критическая точка

С ростом размерности p_c падает: больше соседей — легче связаться.

При плавном изменении p происходит резкое качественное изменение структуры — фазовый переход.

Универсальность

Показатели зависят только от размерности, не от типа решётки. Квадратная, треугольная, соты — все дают одинаковые β, γ, ν в 2D.

Верхняя критическая размерность

При d ≥ 6 показатели становятся среднеполевыми: β = 1, γ = 1, ν = 1/2.

Гиперскейлинг

2β + γ = dν
d_f = d − β/ν
τ = 1 + d/d_f

Корреляционная длина ξ — характерный размер кластеров.

ξ ~ |p − p_c|^{−ν}

При p = p_c: ξ → ∞ — система масштабно-инвариантна. Именно поэтому кластер в критической точке — фрактал.

На пороге бесконечный кластер — фрактал. Его масса растёт как:

M(R) ~ R^{d_f}, d_f = d − β/ν

Для 2D: d_f = 91/48 ≈ 1.896. Для 3D: d_f ≈ 2.52.

Кластер занимает промежуточное положение между линией (d = 1) и плоскостью (d = 2).

В 2D работает дуальность — топологический аргумент.

Для квадратной решётки, связевая перколяция:

  • Строим дуальную решётку
  • Открытому ребру соответствует закрытое дуальное
  • Сквозной путь слева направо существует ⟺ нет пути сверху вниз в дуальной

Отсюда p_c = 1/2 — точный результат (Kramers & Van den Berg, 1981).

На решётке L × L порог размазан:

p_c(L) ≈ p_c + a L^{−1/ν}
P∞(L, p) = L^{−β/ν} f((p − p_c) L^{1/ν})

Это главный инструмент численного определения показателей: кривые для разных L схлопываются в одну при правильных β, ν.

Идея: заменяем блок b × b одним суперузлом. Суперузел занят, если блок «протекает».

Рекурсия: p' = R(p). Неподвижная точка p* = R(p*) — критическая.

Показатели извлекаются из линеаризации: ν = ln(b) / ln(R'(p*)).

Ренормгруппа объясняет универсальность: разные системы имеют одну неподвижную точку.

Поиск кластеров

  • BFS / DFS — просто, O(N)
  • Union-Find — быстро для динамики
  • Hoshen–Kopelman — за один проход, O(N)

Определение порога

  • Монте-Карло — усреднение по реализациям
  • Ньюман–Зифф — быстрый бинарный поиск
  • Скейлинг — экстраполяция L → ∞

Алгоритм BFS

для каждого узла start:
    если start пуст или уже помечен: пропустить
    queue = [start]
    labels[start] = clusterId
    size = 0
    пока queue не пуст:
        idx = queue.pop()
        size++
        для каждого соседа n:
            если n занят и не помечен:
                labels[n] = clusterId
                queue.push(n)
    sizes[clusterId] = size
    clusterId++

  2. Порог p_c — критическая точка появления бесконечного кластера.
  3. Фазовый переход — резкое изменение при плавном p.
  4. Критические показатели β, γ, ν описывают поведение вблизи порога.
  5. Универсальность — показатели зависят только от размерности.
  6. Фрактальность — на пороге кластер самоподобен.
